# Mercado Livre Ofertas Scraper

Projeto de Web Scraping desenvolvido em Python para coletar ofertas do Mercado Livre utilizando Selenium.

## Tecnologias

* Python
* Selenium
* Pandas
* OpenPyXL

## Estrutura

```text
mercado-livre/
│
├── src/
│   ├── mercado_livre_scraper.py
│   └── mercado_livre_scraper.ipynb
│
├── output/
│   └── OfertasMeli.xlsx
│
├── requirements.txt
│
└── README.md
```
